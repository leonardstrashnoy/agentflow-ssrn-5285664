# How we edit this paper

1. Branch from `main` (`git checkout -b describe-the-change`).
2. Edit `paper/main.tex` (and `paper/references.bib` if citations change). Do not edit the SSRN PDF; replace it only when a new version is posted.
3. Open a pull request into `main`.
4. The repo owner (Leonard) merges. If Dmytro is a Write collaborator, he can push branches and open PRs; merge policy is still Leonard's unless that is changed.

This is the same loop as the SDT experiment PR, except here you can press Merge yourself.
